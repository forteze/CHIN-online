LEARN

How to play?

⌨️

MOVE

Use the A and D keys to move across the map. A: move left. D: move right.

⬆️

JUMP

Use the W key to jump over obstacles and platforms.

🔫

COLLECT

Find the ammo scattered around the map so you can shoot the enemies. Each pickup gives only 2 bullets, so every shot counts.

💥

SHOOT

Press J (or K) to shoot. Defeat the boss of each zone to move on to the next one. You can also move with the arrow keys.

☣️

SURVIVE

The ground is solid everywhere. Block walls are solid too, so use them as cover from turrets. Green hearts 💚 give back a life.
